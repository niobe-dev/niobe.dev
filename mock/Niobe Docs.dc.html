Getting started

Installation

Niobe is a single static binary. The installer detects your OS and architecture, verifies the checksum, and places niobe on your PATH.

Quick install

macOS (Apple Silicon and Intel), Linux (x86_64, arm64) and Windows via WSL2.

shellcopy
$ curl -fsSL https://niobe.dev/install.sh | sh

Prefer to inspect first? curl -fsSL https://niobe.dev/install.sh -o install.sh then read it — it's 80 lines.

Pin a versionNIOBE_VERSION=0.9.2 sh install.sh
Custom install dirNIOBE_INSTALL=~/.local/bin sh install.sh

Verify: niobe --version → niobe 0.9.2 (neo)

Authentication

Niobe talks directly to the provider API with your key. Keys are stored in your OS keychain, never in the repo.

$ niobe auth anthropic # or: openai, google
? Paste your API key: ••••••••••••••••
✓ stored in keychain · default model: opus-5

CI or containers: set ANTHROPIC_API_KEY, OPENAI_API_KEY or GOOGLE_API_KEY instead.

Your first session

Run niobe inside a git repo. It indexes the tree, reads NIOBE.md if present, and opens the TUI.

$ cd my-project && niobe
> add etag support to the catalog fetcher
  1. Niobe reads the relevant files and posts a plan with its token estimate.
  2. Edits show as inline diffs. In auto mode they apply immediately; press shift+tab to cycle to confirm or plan-only.
  3. Tests run in the shell pane; the Cost panel updates per tool call.
  4. F4 undoes the last edit group. F10 quits and writes the session log to .niobe/sessions/.
