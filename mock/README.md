# The design mock

The original mock the site was built from, kept because it is where the palette, the type and
the shape of the landing page came from.

It is **not** the site and it is not built or deployed. Its copy is from before the pages were
written against the shipped binary, so some of it describes a product that does not exist:
provider API keys, a different licence, a function-key reference that is not the one the shell
draws. Do not copy a sentence out of here into a page.

`*.dc.html` files carry their own runtime in `support.js`; open one directly in a browser.
